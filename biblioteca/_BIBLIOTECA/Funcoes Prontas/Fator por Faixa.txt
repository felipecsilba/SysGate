// ATENÇÃO: Fórmula (Calculo/Acrescimos/etc.) e Script (Scripts/Scripts,
// Componentes, Fontes Dinamicas, Criticas) são DUAS linguagens diferentes
// dentro do mesmo sistema. Confirmado no corpus desta base:
//   - "def função(){}"     -> 1.203 usos em Scripts/, 0 usos reais em Formulas/
//   - ".find{}" (closure)   -> 334 usos em Scripts/, 0 usos reais em Formulas/
//   - "Dados.tributos.*"    -> 4.932 usos em Scripts/, 0 usos reais em Formulas/
// A versão com "def" abaixo SÓ funciona em Script. Fórmula não aceita
// declarar função nem usar closures do tipo ".find{ }" — nela o fator por
// faixa precisa ser feito com se/senao mesmo (não tem como generalizar numa
// função reutilizável dentro da própria Fórmula).

// =========================================================
// SCRIPT — versão função, reutilizável
// =========================================================
// Origem: PREFEITURA MUNICIPAL DE ANDRADAS — Scripts/Scripts/Atualiza Valor
// Venal.txt, usado pra fator de profundidade/gleba/idade.
// Formato das faixas: [inicio, fim, fator]. Intervalo [inicio, fim) —
// inclui o início, exclui o fim.

def calcularPorFaixa(valor, faixas, padrao = 1) {
  def encontrado = faixas.find { faixa -> valor >= faixa[0] && valor < faixa[1] }
  return encontrado ? encontrado[2] : padrao
}
